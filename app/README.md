# TaskMate

TaskMate is a modern Android reminder application built using Kotlin and Jetpack Compose.

The goal of this project is to create a lightweight, offline-first productivity application that helps users manage daily tasks and reminders without relying on cloud services.

---

## Features

* Add Tasks
* Edit Tasks
* Delete Tasks
* One-Time Reminders
* Recurring Reminders
* Categories
* Priority Levels
* Search
* Backup & Restore
* Dark Mode
* Material Design 3

---

## Technology Stack

* Kotlin
* Jetpack Compose
* MVVM Architecture
* Room Database
* WorkManager
* Material Design 3
* Navigation Compose
