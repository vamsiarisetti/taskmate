# Project Vision

## Purpose

TaskMate is not intended to be another generic to-do list application.

The objective is to create a beautiful, modern, offline-first productivity assistant that can be used daily.

---

## Principles

* Offline First
* Fast
* Lightweight
* No Ads
* No Subscription
* Free Forever
* Clean UI
* Easy to Maintain

---

## Long-Term Vision

Future versions may include:

* Voice Input
* AI Task Suggestions
* Calendar View
* Widgets
* Habit Tracking
* Smart Scheduling
* Local AI Integration
* n8n Integration
