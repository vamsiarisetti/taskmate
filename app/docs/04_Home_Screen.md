# Home Screen

## Objective

Build the first version of the TaskMate home screen using Jetpack Compose.

## Features

- Application title
- Greeting message
- Today's Tasks section
- Reusable TaskCard component
- Dummy task data
- Material 3 theme
- Dark mode support

## Components

- HomeScreen
- TaskCard
- HomeViewModel (temporary)

## Known Limitations

- Uses dummy data
- No Room database
- No navigation
- No add task functionality
- No reminders
